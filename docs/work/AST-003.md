# AST-003 — Missing-asset fallback

Status: VERIFIED
Started: 2026-08-07
Verified: 2026-08-07
Owner: active engineering team

## Goal

Missing or corrupt 3D assets must never crash the app or leave an invisible gameplay/UI object.

## Delivered

- Added `lib/core/widgets/game_asset_view.dart` as the shared AST-002-backed runtime image primitive.
- Missing or corrupt `Image.asset` loads route through deterministic `errorBuilder` fallbacks rather than escaping into gameplay/UI.
- Supports icon, text, registered-asset, and generic missing-image fallbacks.
- Registered-asset fallback chains track visited stable IDs and terminate safely on cycles.
- Meaningful assets expose one image semantic label while decorative assets are excluded from semantics.
- Fallback icon sizing is bounded to 18–64 logical pixels and remains type-safe.
- Added `test/core/widgets/game_asset_view_test.dart` covering missing bundle assets, corrupt bytes, fallback cycles, meaningful semantics, and decorative semantics.
