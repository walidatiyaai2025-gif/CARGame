## Current checkpoint

Establish dependency governance without changing production package versions or runtime behavior:

1. audit direct hosted dependencies against the committed lockfile and their installed license files;
2. document source, constraint, lockfile, licensing, and upgrade-review policy;
3. add an executable dependency-governance contract after package restore;
4. add non-blocking dependency-drift visibility without automatic upgrades;
5. wire the blocking governance contract into normal Flutter CI.

## Acceptance

- direct hosted dependencies resolve from approved `pub.dev` sources and remain aligned between `pubspec.yaml` and `pubspec.lock`;
- unreviewed git/path/custom-host dependencies are rejected;
- each direct hosted dependency has a non-empty installed license file;
- direct dependency versions/licenses are inventoried and reviewed;
- upgrade drift is visible but does not mutate production dependencies automatically;
- focused governance tests, Analyze, full Flutter suite, Debug APK, and artifact upload pass;
- branch is reconciled with current main before merge.
