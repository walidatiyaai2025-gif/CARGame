# ENG-012 — Analytics event schema and privacy gating

## Goal

Introduce a stable, versioned first-party analytics contract without adding a network analytics SDK, processor, persistence path, or gameplay dependency.

## Issue

- GitHub Issue #175
- PR #176
- Branch: `agent/eng-012-analytics-schema`

## Current checkpoint

`IN PROGRESS` — establish a pure-Dart event schema, an application-layer analytics port, and a production composition that is disabled by default and remains fail-closed until both build configuration and an explicit first-party runtime privacy eligibility signal permit collection.

## Architecture

- Domain owns the versioned event vocabulary and property validation.
- Application owns the analytics port.
- An outward adapter owns gating and any future transport integration.
- `AppComposition` owns the process-level analytics boundary.
- No domain/application source may import an analytics SDK.

## Privacy rules

- No Firebase Analytics, GA4, Amplitude, Mixpanel, telemetry backend, or new network dependency is introduced by ENG-012.
- Google UMP advertising consent is not reused as generic first-party analytics consent.
- No analytics consent value is persisted in this checkpoint.
- `ENABLE_ANALYTICS` defaults to `false`.
- Production runtime eligibility defaults to `false` until a separate explicit first-party privacy decision exists.
- No analytics event is persisted, queued, uploaded, or transmitted by the current production composition.

## Acceptance

- Schema version and stable event/property contracts are explicit.
- Unknown events/properties and unsafe/non-scalar values are rejected before an adapter sees them.
- Collection remains disabled without both configuration and runtime privacy eligibility.
- Adapter failures cannot break offline gameplay.
- Existing privacy inventory continues to declare no first-party analytics network processor or transfer.
- Formatting, Analyze, focused tests, full Flutter tests, Debug APK, privacy/security/dependency/catalog, and artifact-security gates pass before VERIFIED.
