## Why this task is active

`TEST-011` is P0 but its own catalog blocker note says acceptance cannot pass until `ADS-007`, `PRIV-003`, and `SEC-002` are completed. `SEC-002` is itself P0 and its declared dependencies (`ENG-006`, `ENG-010`, `ENG-007`) are VERIFIED, so it is the correct dependency-ready primary task.

## Acceptance

- Preserve the existing tracked secret/signing-material scanner and regression policy.
- Verify the locked dependency graph with an enforced lockfile and fail CI on active, non-reviewed Dart/Flutter security advisories.
- Make advisory exceptions explicit, narrow, documented, and machine-validated; no silent suppression.
- Scan generated build artifacts before upload for forbidden signing/private-key/local-secret files and credential-like text payloads without false-positive scanning arbitrary compressed binary bytes.
- Add focused regression tests for dependency advisory parsing/exception policy and artifact inspection.
- Wire all SEC-002 gates into normal Flutter CI while preserving the current ENG-007/security/privacy/dependency/assets/format/analyze/test/debug-APK pipeline.
- Run full CI and record the Debug APK artifact before verification.

## Non-goals

- No dependency upgrades unless a real advisory forces one and the upgrade is separately validated.
- No production signing material, AdMob IDs, or credentials in the repository.
- No replacement of the existing secret-hygiene or dependency-governance controls.
