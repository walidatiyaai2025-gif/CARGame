## Why this task is reopened

PR #35 established the original human/machine threat model and CI security-baseline gate. Current main has since changed materially:

- PRIV-001 now mechanically covers 33 persisted key/prefix families and records the exact current Ads/diagnostics gate truth.
- REL-004 added local corruption snapshot/recovery.
- SHOP-002 and REW-007 added absolute-state transaction journals and reward idempotency state.
- ECON-005 added fail-closed economy schema versioning.
- REL-006 and ENG-010 are now VERIFIED and provide stronger signing/secret handling evidence than the original baseline.
- The old security wording overstates ad disabling: `AdService` request/load/show calls honor `ENABLE_ADS=false`, but `MobileAds.instance.initialize()` still runs from bootstrap and is not yet consent-gated.
- `ENABLE_DIAGNOSTICS` exists in build configuration, but current bootstrap still installs the local redacted logger unconditionally; remote diagnostics remain absent.

## Current-main audit scope

- Reconcile security principles and protected local assets with current persistence/recovery/transaction architecture.
- Correct the Google Mobile Ads trust-boundary/control statement to distinguish request gating from SDK initialization gating.
- Record diagnostics build-gate truth without weakening the existing redaction/local-only guarantees.
- Cross-check machine security controls against PRIV-001 runtime-control truths so privacy/security documentation cannot drift independently.
- Preserve current TLS, untrusted-client, secret-storage, signing, tamper/repackaging, and future-backend assumptions.
- Strengthen deterministic CI checks for protected assets, trust-boundary references, runtime-control parity, and privacy-owned security gaps.

## Acceptance

- No privileged client secret is assumed safe.
- Security network processors exactly match PRIV-001.
- Current Ads and diagnostics gate truth exactly matches PRIV-001.
- Current progress, transaction/reward recovery state, storage recovery snapshot, diagnostics, signing material, and public ad identifiers are classified.
- Threat mitigations reflect current REL-004 / SHOP-002 / REW-007 / ECON-005 / REL-006 / ENG-010 evidence without claiming SEC-002, SEC-003, ADS-007, ENG-013, PRIV-002, or TEST-011 complete.

- Full Flutter CI, tests, Analyze, Debug APK, and artifact upload remain green.
