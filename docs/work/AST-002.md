# AST-002 — Asset manifest and typed registry

Status: VERIFIED
Started: 2026-08-07
Verified: 2026-08-07
Owner: active engineering team

## Scope

Implement the versioned text manifest and typed Dart registry required by `docs/ASSET_CATALOG.md` without admitting binary runtime art.

## Delivered

- Added `assets/3d/manifest.json` with schema version 1 and an intentionally empty asset list while binary admission remains gated.
- Added `lib/core/assets/game_asset.dart` with typed category, render profile, rarity, world, fallback, dimensions, semantics, and stable descriptor contracts.
- Added `lib/core/assets/game_asset_registry.dart` with JSON parsing, immutable ID lookup, category/world/profile queries, duplicate detection, schema checks, path validation, and category/profile constraints.
- Added `test/core/assets/game_asset_registry_test.dart` covering empty manifests, valid typed records, stable queries, duplicate IDs, invalid runtime paths, category/profile mismatches, localization requirements, schema versions, and enum rejection.
- Updated `assets/3d/README.md` so the admission policy reflects the completed registry while keeping binary art blocked by AST-003 and AST-011.

## Acceptance evidence

- Stable IDs, path, category, semantics, fallback, dimensions, rarity, optional world, and profile are all typed.
- Meaningful assets require localization keys; decorative semantics remain explicit.
- Runtime paths are constrained to `assets/3d/runtime/` and filenames must follow the governed `cg_*_<profile>_vNN.webp` grammar.
- Cargo/city/boss/UI/reward/effect/world/environment profile contracts are validated before registry admission.
- Empty manifest is valid, so this work does not silently admit unlicensed or unfallbacked binary art.
- Flutter CI run 110 passed formatting, whitespace integrity, Flutter Analyze, optional-service tests, GameButton tests, the full Flutter test suite, debug APK build, and debug APK artifact upload.
