# AST-002 — Asset manifest and typed registry

Status: IN PROGRESS
Started: 2026-08-07
Owner: active engineering team

## Scope

Implement the versioned text manifest and typed Dart registry required by `docs/ASSET_CATALOG.md` without admitting binary runtime art.

## Required fields

Every asset record must type and validate:

- stable ID
- runtime path
- category
- semantic concept/localization key/decorative state
- fallback contract
- pixel dimensions
- rarity
- optional world slug
- locked render profile

## Acceptance

- Manifest schema is versioned and machine-readable.
- Dart parsing rejects duplicate IDs, unsupported enum values, malformed paths, and invalid dimensions.
- Registry supports stable ID lookup and category/world queries without mutable global state.
- Empty manifest remains valid while binary-art admission is gated by AST-003/AST-011.
- Focused tests cover valid records and validation failures.
- Flutter format, analyze, full tests, and debug APK pass before AST-002 is closed.
