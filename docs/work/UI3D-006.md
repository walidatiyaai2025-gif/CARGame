# UI3D-006 — Responsive screen shell and safe areas

Status: VERIFIED
Started: 2026-08-07
Verified: 2026-08-07
Owner: active engineering team

## Goal

Keep bounded game screens fully visible across supported phone/tablet viewports, accessibility scaling, safe-area cutouts, and temporary viewport reductions without introducing unnecessary scrolling.

## Implementation evidence

- Shared `GameFitView` provides one bounded, scale-down screen primitive.
- Home, Mission Briefing, and Settings use the shared fit shell; long-form screens such as Progress Hub remain scrollable by design.
- `GameFitView` applies outer padding before measuring its `LayoutBuilder`, so the fitted `SizedBox` uses the post-padding viewport instead of accidentally sizing to pre-padding constraints.
- The shell preserves caller directionality and uses `BoxFit.scaleDown`, so content renders at natural size when possible and only scales down when required.
- Settings regression coverage verifies that bounded content does not fall back to `ListView` or `SingleChildScrollView`.
