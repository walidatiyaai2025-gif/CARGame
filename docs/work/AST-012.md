# AST-012 — deterministic asset build validation gate

## Status

IN PROGRESS — source-controlled production hardening while AST-007 commercial artwork/provenance remains externally blocked.

## Goal

Make the runtime asset directory fail closed before new binaries can enter a production candidate. This gate does not manufacture or approve artwork and does not change gameplay.

## Contract

`tool/verify_ast_012_asset_build.py` enforces:

- `assets/3d/manifest.json` is UTF-8 JSON with `schemaVersion: 1` and a non-empty `assets` list;
- every manifest asset has a unique non-empty ID and unique safe runtime path;
- runtime paths stay below `assets/3d/runtime`, use forward slashes and only supported WebP/GLB formats;
- runtime classes are explicit and bounded (`ui`, `boosters`, `rewards`, `boss`, `cargo`, `models`);
- every binary physically present in the runtime tree is declared by the manifest, non-empty, non-symlinked, and below its class byte budget;
- descriptor-only manifest entries are legal so AST-007 can continue to declare future cargo WebP while runtime fallbacks remain authoritative until provenance admission succeeds.

`tool/test_ast_012_asset_build.py` mutation-tests duplicate IDs/paths, traversal, unsupported formats/classes, undeclared binaries, zero-byte binaries, oversized binaries, schema drift, and descriptor-only behavior.

The dedicated `.github/workflows/ast_012_asset_build.yml` workflow runs the real repository validation followed by mutation regressions on asset/tool changes and on main.

## Gameplay preservation

AST-012 changes no gameplay, save, economy, reward, level, or cargo assignment code. GAME-017 remains authoritative: Level 1 starts with 9 products distributed across 3 houses, and cargo volume increases progressively through the 150-level campaign.

## Merge gate

Do not mark VERIFIED or merge until the exact PR head passes AST-012 plus the applicable normal Flutter, Android release-smoke, security/privacy and RT3D workflows. After merge, update this document with the exact commit/run evidence.
