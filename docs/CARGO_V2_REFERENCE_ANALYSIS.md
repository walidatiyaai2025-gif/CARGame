# CARGO V2 REFERENCE ANALYSIS

Nine uploaded mobile-game reference images were inspected for CARGO V2. The references consistently show a premium logistics-game visual system rather than a flat utility UI.

## Locked visual language
- Background: deep navy/near-black, with subtle world-map or atmospheric depth.
- Primary accent: luminous amber/gold for trucks, cargo, rewards, CTA buttons, progress and selected states.
- Contrast: white labels and restrained cool-blue secondary highlights.
- Hero assets: stylized 3D trucks, crates, coins, gifts and containers with upper-left key light, warm rim light and soft ground glow.
- Panels: rounded beveled frames with dark inner surfaces, thin gold/blue edge highlights and controlled bloom.
- World map: dark globe/map presentation with illuminated route/city nodes and cargo progression.
- Slots/rewards: large centered symbols, strong anticipation/reveal glow, particle bursts and coin motion without excessive screen noise.
- Mission gameplay: vertical mobile composition, clear cargo symbols, combo feedback and bottom navigation/HUD separated from the play field.

## Palette
- `#0A1A2F` — base navy
- `#FFC107` — primary gold
- `#FFFFFF` — primary text/high contrast

## UX implications
- One dominant CTA per state.
- Gold communicates action/value/reward; it should not be used as generic decoration everywhere.
- Glow intensity escalates with rarity/reward importance.
- 3D hero objects stay readable on small screens with uncluttered silhouettes.
- Motion should reinforce logistics flow: truck arrival, cargo travel, map unlock, coin flight and slot reveal.
