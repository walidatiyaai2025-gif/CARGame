# CARGO V2 GDD

## Product
- ProjectName: CARGO V2
- CoreLoop: Mission > Reward > Slots > Cards > Tournament
- Target: mobile-first logistics/cargo game with premium stylized 3D presentation
- Primary runtime: Flutter/Dart per repository architecture

## Economy and monetization
- Monetization: IAP, Ads, Pass
- Retention: Daily Spin, Login Streak, Guilds
- Onboarding: 3 steps + first mission free + first spin free

## KPI targets
- D1 retention > 40%
- D7 retention > 15%

## Visual direction
- Palette: #0A1A2F / #FFC107 / #FFFFFF
- Dark premium world-map and logistics presentation
- Gold/amber 3D trucks, boxes, coins and reward objects
- Rounded beveled panels, controlled glow, particles and depth
- Visual hierarchy prioritizes mission start, reward reveal, slot action and progression

## Runtime rule
CARGO V2 must remain compatible with the existing CARGame Flutter architecture and saved-player contracts unless a separately approved migration changes that architecture.
