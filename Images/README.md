# CARGame Visual Asset Library

Branch: `art/asset-library`

This directory contains production-oriented visual assets for CARGame. Assets are organized by category and stored individually rather than as combined concept boards.

## Current structure

- `Vehicles/SportsCar/`
- `Vehicles/SuperCar/`
- `Vehicles/HyperCar/`
- `Roads/`
- `Environment/`
- `Obstacles/`
- `Collectables/`
- `Particles/`
- `UI/`
- `Icons/`
- `Weather/`
- `Skyboxes/`
- `Materials/`
- `References/`

## Asset rules

- One asset per file.
- Transparent PNG where practical.
- No watermark, logo, or embedded text.
- Consistent AAA stylized-realism art direction.
- Unity URP / mobile-first target.
- Naming follows `<Category>_<ViewOrVariant>_<Color>.png` where applicable.
