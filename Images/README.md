# CARGame Visual Asset Library

This directory contains the production visual asset library for CARGame.

Art direction: AAA stylized realism, premium mobile racing, Unity URP, mobile-first, 60 FPS.

Rules:
- One asset per file; no contact sheets or combined boards.
- Transparent background unless an environment/screen requires a scene background.
- No watermark, no external logos, no embedded text unless the asset itself is UI copy.
- Consistent premium blue/orange/black/white/steel visual language.
- PBR-ready references with clean materials, controlled detail, and mobile optimization in mind.

Primary groups:
Vehicles, Roads, Environment, Obstacles, Collectables, VFX, UI, Icons, Garage, Weather, Skyboxes, Materials, AnimationReferences.
